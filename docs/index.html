FAQ

Questions

Can Duet get my game account banned?

Duet never changes game files or game memory. It starts the game the same way HoYoPlay or Steam does, reads your pull history through the same official link the game opens, and talks to HoYoLAB like its website does. That's the same way other popular pity trackers work.

Is signing in to HoYoLAB safe?

You sign in on HoYoLAB's own page inside a Duet window — Duet never sees your password. Afterwards Duet only uses the sign-in to read your Resin and dailies and to claim the daily check-in. If HoYoLAB ever asks for a captcha, Duet opens the official check-in page so you can do it yourself. Sign out anytime from the game page.

Which games work?

Genshin Impact and Honkai: Star Rail get everything: game page, pity, Resin / Trailblaze Power, check-in, codes and reset timers. Wuthering Waves gets the game page and pity tracking (in beta). Neverness to Everness gets the game page and playtime. Minecraft gets the whole launcher.

Windows says "Windows protected your PC"

Duet isn't code-signed yet, so SmartScreen warns about new apps. Click More info → Run anyway. Official downloads are only on this site and on GitHub.

Do I need a Minecraft account?

For Minecraft, yes — you sign in with the Microsoft account that owns Minecraft: Java Edition, on Microsoft's own page. Duet never sees your password. Microsoft sign-in is currently waiting for Mojang's approval for new launchers. Your other games don't need it.

Can I bring my stuff from another launcher?

Yes. Duet copies your instances from the Modrinth App, Dawn (Feather), Prism, MultiMC, CurseForge, ATLauncher, GDLauncher or the official launcher — worlds, mods, packs, settings and servers. The other launcher keeps its files.

Who can see what I'm playing and my pity?

Only the friends you added, and only what you allow. In Friends → Privacy you can look offline, hide what you're playing, hide your server, or stop sharing your pity.

A video background doesn't play on Linux

Use a .webm video, or install the codecs: sudo apt install gstreamer1.0-libav gstreamer1.0-plugins-good.
