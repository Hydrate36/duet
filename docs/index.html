FAQ

Questions

Can Duet get my game account banned?

Duet never changes game files or game memory. It starts the game the same way HoYoPlay or Steam does, reads your pull history through the same official link the game opens, and talks to HoYoLAB like its website does. That's the same way other popular pity trackers work.

Is signing in to HoYoLAB safe?

You sign in on HoYoLAB's own page inside a Duet window, so Duet never sees your password. Afterwards Duet only uses the sign-in to read your Resin and dailies and to claim the daily check-in. Sign out anytime from the game page.

Which games work?

Minecraft gets the whole launcher. Genshin Impact, Honkai: Star Rail, Zenless Zone Zero, Wuthering Waves, Neverness to Everness and Honkai Impact 3rd get their own game page, with pity and dailies where the game supports it. Steam and Epic games show up in your library, and you can add any other game yourself.

Windows says "Windows protected your PC"

Duet isn't code-signed yet, so SmartScreen warns about new apps. Click More info → Run anyway. Official downloads are only on this site and on GitHub.

Do I need a Minecraft account?

For Minecraft, yes: you sign in with the Microsoft account that owns Minecraft: Java Edition, on Microsoft's own page. Duet never sees your password. Your other games don't need it.

Can I bring my stuff from another launcher?

Yes. Duet copies your instances from the Modrinth App, Dawn (Feather), Prism, MultiMC, CurseForge, ATLauncher, GDLauncher or the official launcher: worlds, mods, packs, settings and servers. The other launcher keeps its files.

Who can see what I'm playing?

Only the friends you added, and only what you allow. In Friends → Privacy you can look offline, hide what you're playing, hide your server, or stop sharing your pity.

A video background doesn't play on Linux

Use a .webm video, or install the codecs: sudo apt install gstreamer1.0-libav gstreamer1.0-plugins-good.

Found a bug?

Tell us! In Duet go to Settings → Report a bug (it can add your Duet version and PC details for you), or . Leave a Discord name or email if you'd like an answer.

What does the hardware survey send?

Now and then Duet may ask if you want to share anonymous info about your PC, so we know which hardware to make Duet faster on. It only sends if you say yes, and it shows you everything first: graphics card, processor, memory, operating system, screen size, Java and Duet versions, language, and which Minecraft versions and mod loaders you use. No name, no account, no IP address. You can turn the question off in Settings. The totals are public on the survey page.
