Duet Hardware & Software Survey

What Duet players play on

Every so often Duet asks its players if they'd like to share anonymous info about their PC. These are the results: what's common, what's growing, and what we should make faster.

How this survey works

Duet only sends an answer when a player says yes, and it shows everything first: graphics card, processor, memory, operating system, screen size, Java and Duet versions, language, and which Minecraft versions and mod loaders they use. There's no name, no account and no IP address in it, and each Duet answers once per survey.

Only totals are shown here, never single answers. Entries with very few answers are grouped into "Other". Minecraft versions, mod loaders and Java can have more than one answer per player, so those percentages can add up to more than 100%.
